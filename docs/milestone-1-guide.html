Milestone 1 "Basic rig"

State: In progress, not approved yet

Read this first
  • Goal: a car follows a spline and sits flat on ground geometry, in body or per-wheel mode.
  • Out of scope: wheel spin, suspension, smoothing (bible section 7, "Later").
  • To change anything, write in the notes box under it, press Copy my notes, and paste to Claude.

1. Parts

  • CarRig.ms: the dialog, the build and remove steps, and the rig controller script.

2. Questions for doole

  1. Should wheels spin from distance travelled in a later milestone? Claude recommends: yes, it is the next thing a car shot needs.

3. How to test each step

Step 1: the whole tool

  1. In 3ds Max: Scripting > Run Script, pick E:\REPOS\3D TOOLS\MaxCarRig\CarRig.ms.
  2. Make a Plane with a Noise modifier, a Line spline over it, and a Box car. Select the box, press Use selection as car, pick the spline, add the plane as ground, press Create at car bottom, then Build rig.
  3. Scrub the timeline: the box runs along the spline and tilts to sit on the bumps.

0.12.1: Progress keys stay put

  1. Select the rig, open the Modify panel, press Set run from speed (Keep speed is now ticked).
  2. Graph Editors > Track View - Curve Editor, find the rig's Car Rig modifier > Progress, add a key in the middle and drag it.
  3. The status bar says Keep speed is now off, and its tick in the Speed group is gone.
  4. Click the spline, then another object, then the rig again. The keys stay where you put them.
  5. Move one spline vertex. The keys do not change.
  6. Press Set run from speed again, then move a spline vertex so the spline gets longer. The two Progress keys stretch so the speed stays the same, and no warning shows.

0.12.2: Set run from speed keeps the first key

  1. In the Curve Editor, drag the first Progress key to frame 20.
  2. Press Set run from speed. The first key stays on frame 20; only the last key moves.
  3. Change Cruise speed and press it again. Again only the last key moves.

0.13.0: change a built rig

  1. Open the tool and click a built rig (the green rectangle). The "Change a built rig" panel shows its name and its ground objects.
  2. Make a new Box near the road, select it, press Add selected. The rig rebuilds and the box is in the list; scrub so the car drives over it.
  3. Pick the box in the list and press Remove. The car no longer rides over it.
  4. Name a new object CAR SURFACE002 and press Add CAR SURFACE. It joins the list.
  5. Draw a second spline, press Pick new spline and click it. The car now drives the new spline; your Progress keys and modifier settings are kept.
  6. Ctrl+Z after any of these puts the rig back as it was.

0.14.0: remove puts the car back, grouped cars, kerb bounce

  1. Group the whole car (body plus the four wheel groups, named FRONT_LEFT and so on) into one group. Select it and press Use selection as car: the four wheel buttons fill in by themselves.
  2. Build the rig, scrub to the middle of the run, then press Remove selected rig. The car jumps back to where it was before the rig (0,0,0 if it was modelled there) with every wheel in its place, straight and unspun.
  3. Put a Box 10 cm high across the road as a kerb and add it as ground. Build a Body or Per wheel rig with Realistic body motion on. Scrub over the kerb: the body rises a touch late, goes very slightly past and settles in about half a second, with no shaking.

4. Review checklist (about 30 minutes)

  • Body mode on bumpy ground: car stays on the surface, no sinking.
  • Per-wheel mode: pick four wheels, rebuild; car rocks less on small bumps.
  • Remove selected rig: car stays put, helpers gone, undo works.
  • Pick both front wheels: on a curve both turn the same way, towards the orange aim null. If they turn the wrong way, tell Claude.
  • Bank 5: body rolls out of the turn, wheels stay on the ground.
  • Exclude list: leave the list empty, Build; the car sits on any visible geometry.
  • Simple mode: car rides the spline only, no helpers but the path one.
